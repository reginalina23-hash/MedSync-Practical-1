# MedSync – Smart Medication Scheduling and Reminder Mobile Application

A new Flutter project.
## Project Overview
MedSync is a Flutter-based mobile application designed to help users manage their medications and view their medication schedules and reminders.

## Getting Started
The application provides a simple and user-friendly interface for medication management.

This project is a starting point for a Flutter application.

## Installation and Running
1. Install Flutter SDK and Android Studio.
2. Clone or download this repository.
3. Open the project in Visual Studio Code.
4. Open the terminal and run:

```bash
flutter pub get
flutter run
```

## Project Scope
This project was developed as a front-end mobile application prototype for Practical 1. The application uses sample data and does not include permanent database storage.
